# RadTech

Технологічний мод для Minecraft 1.21.1 про енергетику, а згодом і про ядерну енергетику: від руд і переробки металів до реакторів, радіації та складних машин.

Написаний на **Kotlin** під **NeoForge**.

> Мод у ранній розробці. Усе, що описано в розділі «Плани», ще не реалізовано.

## Що вже є

**Ресурси** (6 металів: олово, алюміній, літій, неодим, титан, вольфрам)
- Руди та сира руда
- Злитки та порошки для кожного металу
- Шматочки олова

**Машини**
- **Дробилка**: дробить сиру руду й блоки руди на порошки (×2), має власне меню з прогрес-баром
- **Піч**: переплавляє порошки й руди у злитки, працює на паливі

**Рецепти**
- Порошок → злиток (піч)
- Сира руда й блок руди → злиток (піч)

## Плани

| Версія | Що додається |
|--------|--------------|
| 0.1 | Усі метали повністю: злитки, шматочки, блоки |
| 0.2 | Дробилка з меню |
| 0.3 | Власні рецепти дробилки |
| 0.4 | Енергосистема: накопичувачі, генератор, кабелі |
| 0.5 | Нові машини (електропіч, прес), спільна база для машин |
| 0.6 | Уран і його переробка |
| 0.7 | Радіація: лічильник, захист, ефекти |
| 0.8 | Простий реактор і парова турбіна |
| 1.0 | Баланс, досягнення, підтримка JEI |

## Вимоги

- Minecraft 1.21.1
- NeoForge 21.1.x
- [Kotlin for Forge](https://github.com/thedarkcolour/KotlinForForge)
- Java 21

## Збірка й запуск

```
./gradlew runClient
./gradlew build
```

Готовий `.jar` з'являється в `build/libs/`.

## Структура проєкту

```
src/main/kotlin/org/tim/radtech/
├── Radtech.kt          точка входу, реєстри предметів і блоків
├── block/              блоки й block entity машин
├── menu/               серверна логіка меню
├── client/             екрани та клієнтські події
└── registry/           реєстри block entity та меню

src/main/resources/
├── assets/radtech/     моделі, текстури, переклади, blockstates
└── data/radtech/       рецепти, таблиці луту, теги
```
